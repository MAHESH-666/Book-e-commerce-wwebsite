# MAHI Books — Bookstore Website

A small front-end bookstore/e-commerce-style website built with HTML, CSS, and Bootstrap. The pages present a book-store theme with navigation across the home, about, contact, and services sections.

## Features

- Bookstore landing page and navigation
- Separate About, Contact, and Services pages
- Image-led layout and responsive Bootstrap navigation
- Custom CSS styling

## Technology

- HTML5
- CSS3
- Bootstrap 5 (CDN stylesheet)

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Use the navigation links to explore the pages.

No server or package installation is required for the static front end.

## Scope

This repository demonstrates a front-end layout. A backend, shopping cart persistence, payment processing, user accounts, and order management are not implemented in the files currently included.

## Future improvements

- Add product detail pages and a searchable catalog.
- Improve form validation and accessibility.
- Connect a backend only when an actual checkout workflow is planned.
